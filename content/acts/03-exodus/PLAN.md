> 3막에서 무엇을 **A급 에피소드**(큰 사건)로, 무엇을 **B급 에피소드**(라이브러리 조립)로 만들지 정한 표 (2026-10-28).
> 파일을 만들 때 이 표의 ref를 그대로 쓴다 (`npm run check:content`가 겹침을 잡는다).

## 막 정보
- `act.json`: keyVerse `출 14:13` ("너희는 두려워 말고 가만히 서서 여호와께서 오늘날 너희를 위하여 행하시는 구원을 보라"). 3막 전체가 "노예를 건져 내시는 하나님" 이야기라서.
- 막 기본 배경: `egypt` (이집트 강가). 홍해 뒤로는 `wilderness`.
- 여정 지도 경로: 이집트(고센·라암셋) → 숙곳 → 홍해 → 마라 → 엘림 → 신 광야 → 르비딤 → 시내산.

## 인물
- **모세**(`moses`) — 주요 인물. A급 `exo-2-basket`에서 공들여 다시 그림 (옷: `prince` 이집트 왕자 ↔ `shepherd` 목자).
- **아론**(`aaron`), **미리암**(`miriam`), **바로**(`pharaoh`) — 키트. 바로는 요셉 시대 바로와 같은 그림을 씀(2막 에피소드도 이 파일로 바꿈).
- 조연(산파, 바로의 딸, 이드로, 십보라, 감독관, 여호수아 …)은 extras.

## 작업 기록
- **2026-10-27 · A급 #1 `exo-2-basket` 「갈대 상자」(출 2) 완성.** beat 45개, 본문 카드 4장(2:3-4 · 2:10 · 2:14 · 2:24-25), 선택지 1개(누이: 숨어서 지켜보기 / 다가가 말 걸기).
  - **모세 새 그림** (`src/characters/moses.ts`, 키트 임시 그림 → 손으로 그린 실루엣): 큰 키·곧은 등·넓은 어깨, 어깨까지 덮는 두건, 네모진 짙은 수염, 등 뒤 겉옷, 키보다 큰 굵은 지팡이(옹이 손잡이·마디). 옷 두 벌: `prince`(이집트 왕자: 금빛 줄무늬 두건·목걸이·짧은 수염, 지팡이 없음) ↔ `shepherd`(기본). exo-3-bush에서 다시 그릴 필요 없음.
  - **옷 기능 확장** (`src/ui/actor.ts`, `characters/index.ts`): 옷(outfit)이 cloth 말고도 머리(hair)·다리(legs)·팔(armL/armR)까지 바꾸고 키(height)도 바꿀 수 있음. 미리암에 `girl`(소녀 때: 풀어 내린 머리, 작은 키) 옷 추가.
  - **나일강 배경** (`src/fx/nile.ts`, `styles/nile.css`): 파피루스 갈대밭·맞은편 왕궁 탑문. mood `nile`, `nile-dusk`, `nile-basket`(갈대 사이에 까딱이며 떠 있는 상자 + 물결), `nile-basket-day`(같은 상자, 셋이 서도 보이게 오른쪽), `nile-found`(건져 연 상자, 빛과 허우적대는 아기 손).
  - 여정 지도 장소 `midian`(미디안) 추가. exo-1-slaves에 bridge, 도감 moses.scene = exo-2-basket.
- **2026-10-27 · A급 #2 `exo-3-bush` 「타지 않는 떨기나무」(출 3:1–4:17) 완성.** beat 45개, 본문 카드 4장(3:2 · 3:7-8 · 3:14-15 · 4:11-12), 선택지 1개(마지막 핑계: “…가겠습니다” / “보낼 만한 자를 보내소서”). 하나님은 voice + 빛(glory)으로만. 다섯 번의 핑계와 다섯 번의 대답이 중심.
  - **호렙산 떨기나무 배경** (`src/fx/bush.ts`, `styles/bush.css`): 뒤로 우뚝 선 화강암 바위산, 비탈에 풀 뜯는 이드로의 양 떼(몇 마리는 고개를 숙였다 듦), 왼쪽 앞에 가시 떨기나무. mood `horeb`·`horeb-dusk`(불 없음), `bush`·`bush-dusk`(불붙었으나 타지 않음: 잎은 짙은 초록 그대로, 뒤 불꽃이 잎을 실루엣으로 비추고 앞 불꽃이 잎 위에서 일렁임, 연기·재 없이 빛 알갱이만 오름), `bush-snake`(같은 떨기나무 + 땅에서 꿈틀대며 고개 드는 뱀). 폰에서는 spread로 모세가 오른쪽, PC에서는 혼자 선 인물을 오른쪽으로 비켜 세움.
  - **모세 옷 `empty`** (`src/characters/moses.ts`): 목자 차림인데 지팡이를 던져 빈손. 뱀 꼬리를 잡으면 `shepherd`로 돌아와 지팡이가 다시 손에.
  - 맨발(신 벗기)은 그림으로 안 하고 서술 + 무릎 꿇기로. exo-2-basket에 bridge 추가, 이 에피소드 bridge → exo-4-return.
- **2026-10-27 · A급 #3 `exo-7-plagues` 「아홉 가지 재앙」(출 7–10) 완성.** beat 45개, 본문 카드 4장(7:3 · 8:19 · 10:7 · 10:28-29), 선택지 1개(우박 전날, 바로의 신하로서: 종과 가축을 집에 들인다 / 들에 그대로 둔다 — 둘 다 실제로 있었던 일, 9:20-21). 지팡이 뱀 → 피 → 개구리 → 이 → 파리 → 악질 → 독종 → 우박 → 메뚜기 → 흑암을 "내 백성을 보내라 → 재앙 → 바로의 흥정 → 다시 굳은 마음" 반복으로. 바로의 흥정(이 땅에서 / 멀리는 말고 / 남정만 / 가축은 두고)이 웃음 포인트.
  - **재앙 효과 라이브러리** (`src/fx/plagues.ts`, `styles/plagues.css`, 약 10초 뒤 저절로 사라짐): fx `frogs`(개구리들이 무대 아래를 폴짝폴짝) `gnats`(이) `flies`(파리 떼) `ash`(풀무의 재 → 독종) `hail`(얼음 알갱이 + 불덩이, 땅에 닿은 불이 번짐) `locusts`(메뚜기 떼 구름이 하늘을 덮고 지나가며 땅이 어두워짐). 개구리는 SVG + GSAP, 나머지는 캔버스 입자(가볍게, 폰에서는 수를 줄임). 모션 줄이기면 멈춘 한 장면.
  - **재앙 배경(mood)**: `nile-blood`(피로 변한 나일: 붉은 강, 천천히 도는 소용돌이, 떠내려가는 죽은 고기 — `fx/nile.ts`에 'blood' 추가), `hail-field`(폭풍 하늘의 보리밭), `darkness`(더듬을 만한 흑암, 멀리 고센 집 몇 채에만 불빛).
  - 술객·신하는 extras(`priest`·`man`). 무대에 넷이 서면 폰에서 오른쪽 사람이 잘려서 `stage.css`에 넷일 때 간격을 좁힘. exo-6-name에 bridge 추가. 다음 이야기(exo-12-passover)가 아직 없어서 이 에피소드 bridge는 없음.
