# 2막 족장들 (창 12–50) — 계획서

> 2막에서 무엇을 **플레이 장면**으로 만들고, 무엇을 **읽기 구간**으로 둘지 정한 표.
> 장면 파일을 만들 때 이 표의 ref를 그대로 쓴다 (`npm run check:content`가 겹침을 잡는다).
> 장면 = 큰 사건(선택지·연출·인물). 읽기 = 본문 + 요약 + 해설 + 퀴즈.

## 막 정보
- `act.json`: mechanic `journey` (여정 지도 + 인물 시점 — 모듈은 아직 없음), keyVerse `창 12:2` ("너로 큰 민족을 이루고 … 너는 복의 근원이 될지라"). 2막 전체가 이 약속이 어떻게 이어지는지에 대한 이야기라서.
- 여정 지도 경로(mechanic 만들 때 참고): 우르 → 하란 → 세겜 → 벧엘·아이 → 이집트 → 헤브론(마므레) → 소돔 → 그랄 → 브엘세바 → 모리아 → 하란(밧단아람) → 얍복 → 세겜 → 벧엘 → 헤브론 → 도단 → 이집트(고센).
